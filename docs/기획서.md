# 0000 게임 기획서
- 게임: 피의 연구실
- 작성자: 이채원

## 개요
- 장르 호러 퍼즐
- 게임 소개 미치광이 과학자에게 붙잡힌 한 소년! 과학자가 돌아오기 전 탈출해야해!
  - 재미 요소 과학자의 눈을 피해 숨거나 피해다니며 탈출하는 스릴감

## 게임 진행
플레이어는 폐쇄된 연구실에서 깨어난다.

연구실의 출입문은 잠겨 있으며, 탈출하기 위해서는 비밀번호를 알아내야 한다.

플레이어는 연구실 곳곳을 조사하여 연구 기록, 메모, 컴퓨터 로그 등의 단서를 수집한다.

수집한 단서에 적힌 정보를 조합하여 출입문의 비밀번호를 추리한다.

비밀번호를 입력하면 정답 여부를 확인할 수 있다.

비밀번호 입력 기회는 총 3회이며, 정답을 맞히면 탈출에 성공한다.

3회 모두 실패하면 보안 시스템이 작동하여 게임 오버가 된다.

## 조작
숫자 1: 연구 기록 조사

숫자 2: 실험실 메모 조사

숫자 3: 컴퓨터 로그 확인

숫자 4: 출입문 비밀번호 입력

숫자 0: 게임 종료

메뉴에 해당하는 숫자를 입력하여 원하는 행동을 선택한다.

비밀번호 입력 시 숫자를 입력하고 Enter 키를 눌러 정답을 확인한다.

## 플레이 Stage
Stage 1. 연구실 탐색

플레이어는 연구실 내부에서 깨어난다.

주변에 있는 연구 기록과 메모를 조사할 수 있다.

단서에는 비밀번호를 구성하는 숫자에 대한 정보가 기록되어 있다.

모든 단서를 조사하지 않아도 비밀번호를 추리할 수 있지만, 단서를 확인할수록 정답을 유추하기 쉬워진다.

Stage 2. 비밀번호 추리

플레이어는 수집한 단서를 바탕으로 세 자리 비밀번호를 추리한다.

비밀번호는 3개의 숫자로 구성되어 있다.

출입문에서 비밀번호를 입력하면 정답 여부가 표시된다.

오답을 입력하면 남은 입력 기회가 1회 감소한다.

Stage 3. 탈출

비밀번호를 정확하게 입력하면 출입문이 열리고 탈출에 성공한다.

입력 기회를 모두 사용하면 보안 시스템이 작동하여 탈출에 실패한다.

게임 종료 후 성공 또는 실패 결과를 확인할 수 있다.
