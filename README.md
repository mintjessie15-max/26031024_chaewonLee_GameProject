# 기말과제
- 성명: 이채원
- 게임이름: 피의 연구실
- 1. 최소 구현 기능
	1. ① 시작 화면
게임 제목을 표시하고 시작하기 또는 종료하기를 선택한다.




② 단서 조사
연구 기록, 메모, 컴퓨터 로그 중 하나를 선택해 조사한다. 각 단서는 암호와 관련된 힌트를 제공한다.




③ 비밀번호 퍼즐
단서에서 얻은 숫자 세 개를 조합해 문을 여는 암호를 입력한다.




④ 제한된 도전 횟수
암호 입력 기회를 3회로 제한한다. 모두 실패하면 게임 오버, 정답이면 탈출 성공이다.




⑤ 결과 화면
탈출 성공 또는 실패를 표시하고 다시 시작하거나 종료할 수 있게 한다.
